SewerOne: autonomous sludge-cleaning robot

SewerOne cleans sludge in sewage treatment plants so fewer people have to work in hazardous conditions. It runs on ROS2 Humble with Nav2 navigation and SLAM mapping.

I built the Gazebo simulation and the RViz2 SLAM setup using LiDAR and odometry. The robot maps confined spaces on its own and navigates around obstacles. We built a working prototype for an industry-hosted hackathon.

1st place, plus an internship at Genex Utility
