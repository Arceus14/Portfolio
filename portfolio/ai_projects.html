About the AI

This project implements the Minimax Search Algorithm, a classic technique for two-player games. The AI explores every possible future game state, assuming both players always make the best move.

Each possible outcome is scored as a win, loss, or draw, and these scores are propagated back through the search tree. The AI then chooses the move that guarantees the best possible result, making it impossible to beat—it will always win when possible or force a draw.

Minesweeper — Knowledge Based AI

An implementation of the CS50 AI Minesweeper agent using logical inference and propositional knowledge.

Mines: 8


About the AI

Unlike a human player making random guesses, this AI uses logical inference to solve the board. Every revealed cell adds a new logical statement describing how many neighboring squares contain mines.

The agent continuously updates its knowledge base, combines related statements, and infers which cells are definitely safe or definitely contain mines. Only when no certain move exists does it make an informed guess, closely mirroring the reasoning process taught in Harvard's CS50 AI course.
